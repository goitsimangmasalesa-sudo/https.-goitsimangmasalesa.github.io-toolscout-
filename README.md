## How to launch

1. Create a free GitHub account.
2. Create a new public repository named `toolscout`.
3. Upload all files from this `launch_kit` folder into the repository root.
4. Open repository `Settings`.
5. Click `Pages` in the left sidebar.
6. Under `Build and deployment`, choose `Deploy from a branch`.
7. Select the `main` branch and `/root` folder.
8. Save.
9. Wait a minute or two for GitHub Pages to publish the site.
10. Visit your live site URL.

## Important before publishing publicly

Before trying to make money from this site, you should:
